========================================
#### 1. Создание ветки feature
========================================

Команда: git branch feature
Описание: Создает новую ветку feature
Результат: Ветка создана успешно

Switched to branch 'feature'
Команда: git checkout feature
Описание: Переключается на ветку feature
Результат: Переключение выполнено

* feature
  main
========================================
#### 2. Просмотр веток
========================================

* feature
  main
  remotes/origin/HEAD -> origin/main
  remotes/origin/main
Команда: git branch -a
Описание: Показывает все ветки (локальные и удаленные)

* feature 318a96c Добавлен детальный отчет по лабораторной работе №5
  main    318a96c Добавлен детальный отчет по лабораторной работе №5
Команда: git branch -v
Описание: Показывает ветки с последними коммитами

========================================
#### 3. Создание коммита в ветке feature
========================================

[feature 64bd55a] Add feature implementation

Команда: git commit -m 'Add feature implementation'
Описание: Создает коммит с новой функциональностью
Результат: Коммит создан в ветке feature
