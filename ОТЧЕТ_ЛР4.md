```bash

```

### 3. Проверка истории коммитов
```bash
$ git log --oneline --all --decorate
```

```bash

```

```bash
$ git status

```

## Использованные команды Git

| Команда | Назначение |
|---------|------------|
| `git remote add origin <URL>` | Подключение удаленного репозитория |
| `git remote -v` | Просмотр списка удаленных репозиториев |
| `git branch -M main` | Переименование текущей ветки в `main` |
| `git push -u origin main` | Отправка изменений и установка отслеживания ветки |
| `git push` | Отправка коммитов на удаленный сервер |
| `git log --oneline` | Просмотр истории коммитов в сокращенном виде |
| `git branch -a` | Просмотр всех веток (локальных и удаленных) |
| `git status` | Проверка состояния рабочей директории |
