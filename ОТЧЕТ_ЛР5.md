## Выполненные задания

### Пункт 1: Полный лог коммитов

**Команда:**
```bash
git log
```

**Описание:** Показывает полную историю коммитов с подробной информацией (автор, дата, сообщение, хеш).

**Результат:**
```
commit fd9d973... (HEAD -> main, origin/main)
Author: novihinm
Date:   Wed Oct 8 12:35:47 2025 +0300
    Добавлена лабораторная работа №5 - История Git
...
```

---

### Пункт 2: Детальные изменения

**Команда:**
```bash
git log -p
```

**Описание:** Показывает лог коммитов с полным diff (построчные изменения файлов).

**Применение:** Полезно для детального анализа изменений в каждом коммите.

---

### Пункт 3: Короткий вид истории

**Команда:**
```bash
git log --oneline
```

**Результат:**
```
fd9d973 (HEAD -> main, origin/main) Добавлена лабораторная работа №5 - История Git
b80fd02 Добавлен отчет по лабораторной работе №4
19624c5 Updated hello.html with modifications
121f197 First Commit
```

**Описание:** Компактный формат (короткий хеш + сообщение коммита) для быстрого просмотра истории.

---

### Пункт 4: Фильтр по автору

**Команда:**
```bash
git log --author="Максим Новыхин"
# или
git log --author="novihinm"
```

**Описание:** Показывает только коммиты указанного автора.

**Результат:** Все 4 коммита в репозитории созданы автором `novihinm`.

---

### Пункт 5: Графическое представление веток

**Команды:**
```bash
# Простой график
git log --graph

# С коротким форматом и декорациями (ветки, теги)
git log --graph --oneline --decorate

# Для всех веток
git log --all --graph --oneline --decorate
```

**Результат:**
```
* fd9d973 (HEAD -> main, origin/main) Добавлена лабораторная работа №5 - История Git
* b80fd02 Добавлен отчет по лабораторной работе №4
* 19624c5 Updated hello.html with modifications
* 121f197 First Commit
```

**Описание:** Показывает структуру веток в ASCII-графике (полезно при работе с несколькими ветками).

---

### Пункт 6: Ограничение количества записей

**Команда:**
```bash
git log -n 2
```

**Описание:** Показывает только последние N коммитов (в данном случае 2).

**Результат:**
```
commit fd9d973...
    Добавлена лабораторная работа №5 - История Git

commit b80fd02...
    Добавлен отчет по лабораторной работе №4
```

---

### Пункт 7: Поиск по сообщению коммита

**Команда:**
```bash
git log --grep="Second"
# или с игнорированием регистра
git log --grep="commit" -i
```

**Описание:** Фильтрует коммиты по ключевым словам в сообщении.

**Результат:** Найдены коммиты, содержащие слово "commit" в описании.

---

### Пункт 8: Фильтрация по дате

**Команды:**
```bash
# За последний месяц
git log --since=1.month.ago

# В определенный период
git log --since=1.month.ago --until=1.week.ago

# Другие форматы дат
git log --since="2025-09-01"
git log --after={1.week.ago}
```

**Описание:** Показывает коммиты в указанном временном диапазоне.

**Результат:** Все 4 коммита сделаны в последний месяц.

---

### Пункт 9: Сочетание параметров

**Команда:**
```bash
git log --author="novihinm" --since=1.month.ago --oneline
```

**Описание:** Комбинирует несколько фильтров (автор + дата + формат вывода).

**Результат:** Короткий список коммитов автора за указанный период.

---

### Пункт 10: Сравнение изменений и авторство

#### 10a. Изменения с последнего коммита
```bash
git diff HEAD
```
**Описание:** Показывает незакоммиченные изменения в рабочей директории.

#### 10b. Изменения с предпоследнего коммита
```bash
git diff HEAD^
```
**Описание:** Сравнивает текущее состояние с коммитом до последнего.

#### 10c. Статистика изменений
```bash
git diff --stat HEAD^
```
**Результат:**
```
hello.html | 2 +-
1 file changed, 1 insertion(+), 1 deletion(-)
```

#### 10d. Авторство строк
```bash
git blame hello.html
```
**Результат:**
```
19624c59 (novihinm 2025-09-30 23:57:05 +0300 1) <h1>Hello, world!!! Version 3</h1>
```
**Описание:** Показывает, кто и когда изменял каждую строку файла.

---

### Пункт 11: Самостоятельные задания

#### 11a. История с переименованиями
```bash
git log --follow hello.html
```
**Описание:** Отслеживает историю файла даже при переименовании.

#### 11b. Формат: одна строка на коммит
```bash
git log --pretty=oneline
```
**Описание:** Полный хеш + сообщение в одной строке.

#### 11c. Кастомный формат с графом
```bash
git log --pretty=format:"%h %s" --graph
```
**Описание:** Настраиваемый формат вывода (%h - короткий хеш, %s - сообщение).

#### 11d. Коммиты за последнюю неделю
```bash
git log --author='novihinm' --after={1.week.ago} --pretty=oneline --abbrev-commit
```
**Описание:** Короткие коммиты автора за последнюю неделю.

#### 11e. Детали последнего коммита
```bash
git show HEAD
```
**Описание:** Полная информация о последнем коммите (метаданные + diff).

#### 11f. Содержимое файла в ветке
```bash
git show main:hello.html
```
**Результат:**
```html
<h1>Hello, world!!! Version 3</h1>
```

#### 11g. Статистика всех коммитов
```bash
git log --stat
```
**Описание:** Список коммитов с краткой статистикой изменений файлов.

#### 11h. Поиск по содержимому
```bash
git log -S "Hello" --oneline
```
**Описание:** Находит коммиты, где добавлена/удалена строка "Hello".

**Результат:**
```
19624c5 Updated hello.html with modifications
```

## Освоенные параметры Git

### Параметры `git log`:

| Параметр | Назначение |
|----------|------------|
| `--oneline` | Компактный формат (хеш + сообщение) |
| `--graph` | Графическое представление веток |
| `--decorate` | Показать ветки и теги |
| `--all` | История всех веток |
| `-n <число>` | Ограничение количества записей |
| `-p` | Показать diff для каждого коммита |
| `--stat` | Статистика изменений файлов |
| `--author="<имя>"` | Фильтр по автору |
| `--grep="<текст>"` | Поиск по сообщению коммита |
| `--since` / `--after` | Коммиты после указанной даты |
| `--until` / `--before` | Коммиты до указанной даты |
| `--follow` | Отслеживание переименований файла |
| `--pretty=<формат>` | Настройка формата вывода |
| `-S "<текст>"` | Поиск по содержимому изменений |
| `--no-merges` | Исключить merge-коммиты |

### Другие команды:

| Команда | Назначение |
|---------|------------|
| `git diff HEAD` | Сравнение с последним коммитом |
| `git diff HEAD^` | Сравнение с предпоследним коммитом |
| `git diff --stat` | Статистика изменений |
| `git blame <файл>` | Авторство каждой строки |
| `git show <коммит>` | Детали конкретного коммита |
| `git show <ветка>:<файл>` | Содержимое файла в ветке |
